# Project skills

Use the installed TypeSafe skill at `.agents/skills/typesafe-ai/SKILL.md` when working on this project. Read its guidance and apply it where relevant, particularly to AI-powered evidence selection, ranking and verification.

Before adding or changing a TypeSafe integration, consult the live documentation and relevant cookbook as the skill requires. Preserve the project's scope, reference traceability and cost limits; evaluate model judgments on representative evidence rather than treating typed output as proof of correctness.

# Design preferences

Do not use cursive or handwriting fonts anywhere in the product, including canvas notes, labels, saved ideas and exports. Use the existing plain sans-serif typography. Keep the illustrated doodles.
